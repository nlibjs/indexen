# @nlib/indexen

**Maintenance ended on 2026-10-11.** No further releases, fixes or dependency
updates are planned. Existing releases remain available.

Index generation is small enough to keep as a script in each project. See the
[migration guide](MIGRATION.md) and the dependency-free
[example script](examples/generate-index.mjs) to remove the package dependency.

A command line tool to generate index files.

## Historical usage

The following describes the existing CLI. Patterns are relative to the output
directory when `--output` is specified, or to the current directory otherwise.

```
Usage: npx @nlib/indexen [options] <patterns...>

Arguments:
  patterns                     Patterns of files to be included. It will be passed to fast-glob.

Options:
  -o, --output <path>          A path where the result is written to.
  -e, --exclude <patterns...>  Patterns of files to be excluded. It will be passed to fast-glob.
  --noext                      It true, the output will be [export * from "./a"] not [export * from
                               "./a.js"].
  -V, --version                output the version number
  -h, --help                   display help for command
```

Assume you have files below:

```
src/file1.ts
src/file1.test.ts
src/file2.ts
src/dir1/file3.ts
src/dir1/file4.ts
src/dir2/file5.ts
src/file6.private.ts
```

Then execute `@nlib/indexen`:

```
npx @nlib/indexen --output src/index.ts "**/*.ts"
```

`@nlib/indexen` generates `src/index.ts`:

```typescript
// Generated by @nlib/indexen
export * from './file1';
export * from './file2';
export * from './dir1/file3';
export * from './dir1/file4';
export * from './dir2/file5';
```
